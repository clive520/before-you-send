# 按下送出之前：小宇的網路生活

一個給國小高年級及國中學生的繁體中文互動故事。八個決策節點各有四個選項，故事結合網路使用、網路言論、隱私、求助與修復；學生完成故事後，會依自己的每個選擇看到教育及法律觀點與不同結局。

網頁不需要帳號或後端。進度保存在瀏覽器的 localStorage；共用裝置可由首頁清除進度。

## 本機執行

在此資料夾執行 `python -m http.server 8765`，並開啟 `http://localhost:8765/`。

執行 `node tests/story.test.cjs` 可檢查所有 65,536 條選擇路徑及結局回顧。

本故事不是診斷工具，法律內容為教育用途；具體責任需依個案與現行法律判斷。
